# 包裹物理真实性审计

## A1 本轮计划 · 2026-11-21

在 ubun 以冻结的 Stage 2.5 P6 种子 1726481、8,192 路、2 ms、2,385 步复现一次，另用原 P6 入口对照。复现须匹配逐材质通过数、末态双指捕获数、非有限及几何越界数与 343.97 N 峰值（0.01 N）。单指逐帧取最大值，以严格超过 50 N 的环境数为分子。保留前 20 与全部末段失败样本的参数、逐帧波形，按最后 100 步各门槛和峰值力项归因。超过给定筛查线时提出最小修复及复验门禁。

以原加载窗各复算一次四材质刚度。PE 比较指垫到质心的分离与材料应变，并审查同状态同网格证据。只在能辨认因果时分配几何与求解器的贡献。如现有数据不支持外推，保留原 DR 上界。
在 2 ms 冻结探针上按材质分别做一次名义对照及 Tier 1 范围内的敏感性试验。气泡膜同时缩小两项绝对偏差且保持原脱手门禁，PE 11.25 mm 时长偏差减小且保留深浅顺序，才接受相应参数可解释性。使用归档作仿真间比较。原整包 20 项持锁运行一次。未取得实物包络前只给阶段性训练准入意见。
