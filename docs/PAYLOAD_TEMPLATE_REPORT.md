# 统一内容物模板验收

## Step 3 · 接入计划

在 `ubun` 以 2 ms 验证模板注入路径。P1 各运行一次冻结门禁 A 的原工况，并对四材质单独断言 3.0 s 悬停；重跑既有 20 项整包测试。P6 在 RTX 5090 上以固定种子抽取 8,192 路异质 X，运行一次 2,385 步侧抓与悬停批次。复用 Stage 2 动作生成与 CUDA Graph 计时，预热与捕获时间单独记录。对整批检查有限性、完整步数、逐块不穿桌、压陷合法，再报告成功悬停数、有效与总吞吐，墙钟与冻结 1.119 s 基线按约十倍以内比较。P1 失败时检查刚性约束、抓取几何与腕力，P6 超预算时定位模板约束的 GPU 开销。冻结代理及其状态契约继续作为对照。

首轮完整批次沿用开环名义轨迹并按质量配置法向力。8,192 路均完成推进，3.174 s，78 路满足稳定悬停，结束时 8,124 路双指捕获。诊断回合显示横摆是主因。复测在名义轨迹上增加夹爪平移反馈，以载荷质心和速度减小摆幅，修正位移限于各轴 ±100 mm。保持 200 ms、20 mm/s、双侧捕获和零支撑判据。P6 按任务指定的吞吐量验收，另按同数量级要求检查只计合格悬停的有效吞吐。完整稳定率独立报告，原 Stage 2 测试仍使用原验收。

最终回归补查压透硬核时的桌面与腕部反力。P4 增加实际接触耦合的松散样本和零死区对照各一次，两路用同一段含倾斜的夹爪轨迹。检查出现延迟止挡以及不同的腕力与力矩，并在悬空停留末 200 ms 用 1 mN 容差比较净拉力与重力。该容差适用于力平衡的数值核对。

## 模型与接入

`PayloadParamsX` 包含 21 个标量，使用同一四块拓扑。每步四轮投影，每轮处理六条拉伸边、软折弯、硬转角限位和独立桌面支承。步末以两端等反向的冲量处理内部阻尼，并按各块法向冲量限制桌面摩擦。零柔度和零压陷由参数取值给出。

```python
params = PayloadParamsX.from_presets(config, ["rigid_box", "fluffy_pillow"], device="cuda")
sim = MacroParcelSim(proxy, payload=UnifiedPayloadTemplate(params))
state = sim.initial_state()
result = sim.step(state, action)
critic_observation = sim.get_privileged_state(result.state)  # [B, 54]
```

`proxy` 和模板使用同一批量、设备、浮点类型和 2 ms 步长。调用者提供经几何标定的 `ProxyParams.S_bag` 初始预算。填充率限制内部死区，并以等比例截面周长差约束初始余料。两指的压陷沿同一挂点插值进入几何门控，进给增量至多 20 mm，预算增量受压缩后截面周长减少量限制。封装层用单步预算调用冻结代理。挂点法向偏移通过同一个雅可比计算速度及回传力，压陷方向的柔索功率记录在 `PayloadParcelState.indentation_power`。现有刚体入口可继续独立使用。

## Stage 2.5 同袋异物验收计划

在 `ubun` 使用同一名义 PE 代理、外形和初始余料，对书、衣物和枕头各运行一次下压、收拢与提拉。硬书要求全程零捕获、零拉力并通过独立侧抓。两种软物要求由实测压陷增加进给与余料，之后双侧捕获并离台。厚被沿用 25 mm 微提拉与 150 ms 停留。

轻包的同一组侧向指垫行程分别经过内容物侧壁和壁面上方各一次。经过侧壁时检查水平反力超过桌面库仑极限、包裹同向滑移和实际进给低于原捕获门槛。保留过压与松散动量检查。复跑旧 Stage 2 代理和硬盒门禁 A，验证省略新预算字段时沿用原路径。再以 2 ms 运行压力测试及 RTX 5090 8,192 路吞吐。失败时记录首个不匹配的力、几何或捕获条件，修复后复查相应验收。
