## 单环境耗时

`ubun` 的 i9-14900KF，PyTorch `2.15.0+cpu` 单线程，四材质各测一次 4.77 s 侧抓包裹回合并记录完整探针波形。2 ms 墙钟 0.674–0.698 s，1 ms 为 1.365–1.428 s。2 ms 相对归档的 142 节点 GPU Warp 回合耗时比为 773–861 倍，相对 200 节点为 6,111–6,329 倍。归档基线是同机器 539.12–579.86 s 和 4,263.54 s。比较对象分别为代理探针和完整机器人柔性整袋仿真，衡量的是这一对工作负载的墙钟时间差。

## 接口契约

- `LumpedContactProxy(params, dt, *, ablation_rigid_snap=False)` 从 `initial_state()` 返回 `[B, 2, 6]` 浮点张量。左右指排列固定，通道依次为 `slack` m、`capture` 0/1、`slip_cum` m、`hold_time` s、`feed_depth` m、`peak_T` N。1–2 ms 步长，压测采用 float32，宏观对齐采用 float64。
- `step(state, inputs) -> ContactStep` 接收 `ContactInputs`。指垫与挂载点的世界位置和速度各为 `[B, 2, 3]`，质心为 `[B, 3]`，法向力、内收速度、进给和对齐余弦为 `[B, 2]`。返回新状态、每指作用在包裹上的力与绕质心力矩，以及张力、滑移率和弹性量。`validate_inputs(state, inputs)` 用于外部输入边界检查。
- `ProxyParams` 共享物理参数为 `[B, 1]`，`mu_eff` 与 `L0` 为 `[B, 2]`。配置的 Stage 1 刚度及 Tier 1 范围沿用整袋口径，名义 `proxy.k` 为每根柔索的刚度。`ablation_rigid_snap` 使用相同张量接口，以距离和法向阈值捕获，关闭余料更新与滑移，使用高刚度单向连接。
- `MacroParcelSim(proxy, mass_kg, com_offset, *, half_extents=..., table_friction=...)` 的 `step(state, action) -> ParcelStep` 以刚体位姿推进，返回世界轴下绕指尖中点的腕部六维力／力矩、台面支撑和净空。标准探针为 `run_top_press`、`run_side_grasp_and_hover`、`run_controlled_release`、`run_suspended_load_ramp`。

## Milestone 2 补充验收计划

按用户要求优先补原里程碑的 D、E 两项。D 在现有极端动作测试中将实际递推从每档 100,000 次扩至 1,000,000 次，固定 16 路和种子，对 1 ms 与 2 ms 各运行一次。每步验证状态和力有限、余料守恒及滑移单调，保留原张力上限和必须实际经历滑移、单指释放的条件。

E 复用 `MacroParcelSim.step` 与同一个 4.77 s 侧抓探针，RTX 5090 上运行 512／2,048／4,096／8,192 路各一次计时，采用 2 ms 步长、float32、四种材料循环排列，保留抓持、抬升、至少 0.20 s 连续稳定悬停和状态有限指标。预热和建图单独计时，正式区间用 CUDA 同步，采集实际批次墙钟、有效抓取数、环境步/s、仿真秒/墙钟秒和峰值显存。相对高保真单环境保留聚合吞吐倍率及工作负载范围；抓取验收失败的环境不计有效吞吐。两项都通过后再进入下一里程碑。

### D 百万步极端动作
