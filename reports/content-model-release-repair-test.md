# 内容物 I-24 卸载释放修复检查

## 范围与方法

修复压密 weld 依赖自身维持的压缩量而不能释放的问题；增加外部围压条件、5 ms 载荷滤波和原协议 0.05 N 接触阈值。压密 weld 时间常数从 1 ms 改为 2 ms，几何限位与普通阻尼不变。

计划及各轮失败定位见 [实验报告](../test/content_model/REPORT.md)“松爪释放与压密互锁修复”。正式使用 `flock /tmp/claude-gpu.lock` 与 `/home/ubuntu/Dev/Envs/mjwarp/bin/python -B validate_model.py`；输出目录为 `release_repair_400us/` 和 `release_repair_200us/`。检查 M1、四项 M2、步长一致、静置/能量、采样器、公共入口和连续抓放。

## 探索记录

- 原版自由双轴压密块 0.2 s 后 12 个 weld 未释放，残余归一化压缩 0.949715，复现自锁。
- 外载门控的初版能解锁，但未解决全部步长差；渐变焊接、连续势能加成比例阻尼均发生夹持退化，不采纳。
- 外载滤波＋2 ms weld 候选：单轴/双轴实际卸载、四指垫实际压紧释放通过；2×2×2 块开启时扣除外功能量回升最大约 1.3e−7，卸载能量回升最大约 0.23%，均 <1%。
- 2 ms 探索的易弯物端部转角步长差 0.728°，易压物端部滑移 4.437 mm，符合原线；4 ms 候选未解决一致性，不采纳。
- 直接角度惩罚候选导致强弯曲失稳与冲量隔离检查失败，已撤回。原强弯曲面外失稳仍未关闭。
- 首次动作入口仅开回原宽度外 2 mm，物体仍与圆角接触；修正为充分张开，并让再夹从当前指垫位置开始，避免入口瞬移。对象不重置。
