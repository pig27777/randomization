# 薄膜＋颗粒 GPU 5 秒录像检查

时间：2026-11-09，机器 ubun / RTX 5090。

结论：GPU 连续 5 s 仿真和视频已完成；64 个自由球粒、98 个 2D flex 膜顶点，实际保存状态后软件渲染。

- 修改范围：既有 benchmark 增加可选 GPU 轨迹记录与明确标记的诊断续跑选项；新增渲染入口，复用统一平台 Mesa 上下文。默认测速停止规则保留，未改膜/颗粒物理或判定阈值。
- 执行：持 `flock /tmp/claude-gpu.lock`，Newton 单环境、dt=0.5 ms、10000 步；命令与本轮预写计划见[实验报告](../test/flex_granular/REPORT.md)。
- 物理记录：完成 0–5 s，501×742 的 qpos 数组、100 Hz，无非有限；原始标志 0、未出袋，峰值接触穿透 0.8654 mm、外层迭代 14。步进墙钟 287.564 s，含采样检查 289.364 s。
- 视频：H.264、1280×600、25 fps、126 帧、5.04 s（含 t=0 与 t=5 s）；1 倍速、无插值或轨迹重算，实际渲染器 llvmpipe。首/中/末帧视觉检查通过，ffprobe 与完整 ffmpeg 解码通过。
- 静态检查：新/改 Python AST 解析通过；GPU 结果源码 SHA 与运行时版本匹配；轨迹时间严格递增、间隔 0.01 s，渲染 manifest 的采样数、帧数、源 SHA 已核对。视频 SHA 保存在检查 JSON。
- 限制：理想拉伸膜、预设鼓形、直径 16 mm 粗球粒；未实物标定，不含机械臂抓取，不能据此认定真实袋壁响应准确。一次展示运行不作为重复测速结论。
