# 抓取任务与评估协议（v2，以 YAM 为标准）

策略训练、仿真评估和真机评估共用这里的定义。改这里等于改论文的任务：先和总体判断会话确认、告知用户，再同步 `../../paper/rss2027_plan.md`，并在文末“修改记录”写明。

状态：**2026-11-05 v2**（用户确认以 YAM 为标准）。v1 的侧夹流程保留为“侧夹”方式；新增“顶面抓”方式。v2 在内容物模型 v1.2 完成后生效，此前策略线仍按 v1 做协议对齐。数值暂定，生效后不再随实验调整，除非走上面的修改流程。

**平台标准**：i2rt YAM 机械臂 + 平行夹爪。行程 95 mm（来自经销商资料，待实测确认是否等于最大开口）；最大夹持力未知，待实测，实测前夹持力上限暂用 50 N；指尖尺寸待实测，实测前暂用 20 mm 宽 × 40 mm 高。

## 任务

单个软包放在桌面上，夹爪从上方抓起，水平搬运 0.5 m，放到目标区域（以搬运终点为中心的 0.2 × 0.2 m 方框）。

**任务范围**：YAM 的开口只有约 95 mm，大多数软包裹（宽 160–500 mm）无法从两侧整体夹住。因此：
- **软物**（易弯物、易压物）和**松装袋**：主要靠顶面抓（指尖压入表面，捏住一块，把整个物体带起来），也允许在尺寸合适时侧夹；
- **硬物**：只包括至少有一个水平尺寸 ≤ 80 mm、能侧夹的小件（小盒子、平放的瓶子）；更宽的硬盒、书不在任务范围内（平行夹爪从顶面无法抓起）。

## 动作：抓取参数

策略每次输出一组抓取参数，执行由下面的固定流程完成：

| 参数 | 范围 | 说明 |
|---|---|---|
| 抓取方式 m | {侧夹, 顶面抓} | 侧夹只在闭合方向上的物体尺寸 ≤ 85 mm 时可选，否则执行器判为不可执行（计为夹取失败） |
| 夹持中心 (u, v) | [−0.5, 0.5]² | 相对俯视包围盒中心，按包围盒尺寸归一化 |
| 夹持朝向 ψ | [0, π) | 夹爪闭合方向与包围盒长边的夹角 |
| 下降前开口 w | [20, 95] mm | 顶面抓时两指下降前的间距；侧夹时取 95 mm |
| 压入深度 d | [0, 40] mm，且 ≤ 0.6 × 物体高度 | 仅顶面抓：指尖底端低于物体顶面的深度 |
| 目标夹持力 F | [2, F_max] N | 力控：达到后在提起和搬运中维持；F_max 暂用 50 N，实测后改 |
| 提起速度 | [0.05, 0.3] m/s | |
| 搬运峰值加速度 | [0.5, 4] m/s² | |

## 执行流程（冻结）

| 阶段 | 规定 |
|---|---|
| 静置 | 包裹在桌面上静置 0.3 s。随机种子决定包裹的摆放朝向，因此决定搬运方向相对夹爪的角度 |
| 接近与合拢（侧夹） | 两指以 25 mm/s 各自接近，接触（> 0.05 N）后等待另一侧；两侧都接触后合拢。合拢阶段最长 8 s，或到夹爪最小间隙为止；超时后带着当时的夹持力继续执行 |
| 下压与合拢（顶面抓） | 夹爪张开到 w，竖直下降到指尖接触顶面（任一指 > 0.05 N），再以 10 mm/s 继续下压 d；**从任一指接触起**，两指竖直接触力合计达到 20 N 即停止下压。然后以 25 mm/s 合拢，直到夹持力读数达到 F 或最小间隙，最长 8 s。夹持力读数 = 指尖真实横向接触力 + 捏住后的等效夹紧弹簧力（与真实夹爪读到的总夹持力一致） |
| 夹持力控制 | **力控**：开口随力误差调整，力不足就合、超过就松，最多比接触点多松 5 mm；提起和搬运中持续维持 F。控制用 5 ms 低通的力读数，忽略单步接触尖峰 |
| 提起 | 以给定速度提起 0.25 m，保持 0.2 s |
| 搬运 | 水平 0.5 m，摆线轨迹，峰值加速度为给定值；到位后保持 0.3 s |
| 放下与松开 | 以 0.2 m/s 下放，桌面承担 30% 重量（或到达离原高度 5 mm）时停下；每指张开 30 mm，等待 0.5 s |
| 指尖 | 按 YAM 指尖实测尺寸；实测前暂用 20 mm 宽 × 40 mm 高，棱边 2 mm 圆角；仿真中指尖–物体接触刚度约 40 N/mm；摩擦取包裹的表面摩擦参数 |

内容物的响应定义（`../content_model/README.md` 的 R1–R3）是参数的标准测法，仍用 40 × 40 mm 指垫，与执行任务用的夹爪无关。

## 结果判定（冻结，按事件先后，先发生者为准）

| 结果 | 判定 |
|---|---|
| 过度挤压 | 任意时刻力读数（两指法向力平均，20 ms 低通）超过该物品类别的阈值：易压物 15 N，易弯物 25 N，硬物不设（以 50 N 夹爪上限为界） |
| 夹取失败 | 提起并保持后，物体仍与桌面接触，或提起阶段两指同时失去接触超过 50 ms |
| 掉落 | 搬运中两指同时失去接触超过 50 ms，或搬运结束后质心回到桌面附近 |
| 成功 | 松开后质心在目标方框内，且以上都未发生 |
| 仿真失败 | 见下节 |

**安全阈值对所有训练条件相同**：刚体基线（R1）的物体也带对应的类别标签和阈值（标签取自同一次采样的类别），类别不作为策略输入。这样 R1 与其他条件的差别只来自物体动力学，不来自安全目标。

## 仿真失败（sim_fail）

- **确认为仿真失败**：出现非有限值；关节或压密越过限位超过 20%；（Newton 等有单元的后端）单元翻转。
- **只作诊断触发、不单独判失败**：任一段相对指垫或相对物体质心的速度超过 1 m/s。触发时检查上面的证据；没有证据时按物理结果（掉落等）判定，并在日志中标记。
- **报告方式**：每个条件都报告总尝试数、有效结果数和仿真失败数；成功率同时给出按有效结果计算的值，以及把仿真失败计为失败的下限值。配对比较时，一侧仿真失败的样本两侧都剔除，剔除数单独报告。

## 观测

相机配置（2026-11-05 用户确认）：单臂 YAM；一台固定在桌面正上方的 RGB 相机（俯视），一台手腕 RGB 相机。没有深度相机。两台都做内外参标定，俯视相机另做桌面平面的单应标定。

- **俯视（固定相机）**：分割包裹轮廓，得到有向包围盒的长、宽、朝向，以及俯视填充比（轮廓面积 / 包围盒面积；长方体约 1，平放圆柱约 1，椭球约 0.79）。
- **侧视（手腕相机）**：抓取前，手腕相机移到相对包围盒固定的侧视位姿（沿包围盒短边方向水平看向包裹中部，距离 0.4 m），分割侧面轮廓，得到高度 H 和边缘高度比（包围盒边缘一圈的平均高度 / 最大高度，由侧面轮廓计算；长方体约 1，平放圆柱和椭球明显小于 1）。
- 只用轮廓的几何量，不用颜色和纹理作为策略输入。仿真中不做图像渲染，直接由几何计算同样的投影轮廓和特征。
- 执行顶面抓时，指尖接触高度另作实测，执行器用它把 d 限制在 ≤ 0.6 × 实测高度。
- 可选：夹紧过程中前 10 mm 的夹持力–开口曲线。
- 质量、刚度等不能直接观测的量不作为输入。

## 单次评估接口

```
evaluate(object_spec, grasp_params, seed) -> {
    outcome: "success" | "drop" | "grasp_fail" | "over_squeeze" | "sim_fail",
    max_grip_force_N, slip_mm, lift_height_mm, wall_s
}
```

`object_spec` 在降阶模型里是 κ（含类别标签）；真机上是物品编号。同一个 `seed` 决定包裹的初始摆放，保证可复现。

## 开发集与测试集分开

- 训练、调参、任务调整只能用仿真物体和“开发用”真实物品。
- 真机正式评估的物品在实验前列出并封存，不参与任何调参；评估次数、种子和统计方法在实验前写定。

## 修改记录

- 2026-11-06 v2.2（总体判断会话，已告知用户）：①顶面抓下压的 20 N 竖直力限制从“任一指接触”起生效（原来只在两指都接触后生效）；②夹持力读数 = 真实横向接触力 + 等效夹紧弹簧力，力控和过度挤压都用它。原因：v1.2 E5 随机扫描的 20 例仿真失败全部发生在捏住之前——一指先接触时继续下压（14 例），或合拢时真实接触力没有被力控限制（6 例），这两种情况在真实夹爪上都不会发生。

- 2026-11-06 v2.1（总体判断会话，已告知用户）：①提起高度 0.1 m → 0.25 m；②“夹取失败”由“质心升高不足 50 mm”改为“提起保持后物体仍与桌面接触”；③顶面抓的下压在两指竖直接触力合计达到 20 N 时提前停止。原因：v1.2 效果模型验收中，较大的软物（易压物锚点 0.35 m 长）从顶面中心捏起时会像真实枕头一样向两侧下垂，提 0.1 m 时质心只升高 30–43 mm、两端仍在桌上，被判失败；真实分拣会提得更高，判据应看“是否离开桌面”。深压入时易弯物出现越限仿真失败，真实夹爪也压不穿物体，下压应受力限制。`policy/env.py` 需同步。
