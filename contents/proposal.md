# 物流软包分拣：面向任务的统一内容物模型

2026 年 11 月 3 日｜开题报告（合并组会讨论稿与第 45 周周报）

> **核心想法：A = X · B。共用一套软包建模模板 B，通过改变物体参数 X，生成抓取响应不同的具体软包 A，为分拣策略提供随机化训练环境。模型需要保留夹紧、提起和搬运中的关键差异，建模精度由真实任务表现决定。**

当前处于方案设计阶段：分段模型尚未实现，策略尚未训练，参数尚无实物标定。本阶段先完成内容物建模，策略训练以后再做。

## 1. 要解决什么问题

物流分拣面对的软包千差万别。外层袋子有 PE 快递袋、牛皮纸袋、纸板文件封、气泡袋；里面可能是叠好的衣服、揉成团的衣服、枕头，也可能是书和硬盒。即使外包装相近，夹取时也可能出现不同情况：有的很快顶住，有的被压扁，有的提起后下垂，有的在搬运时滑脱或重心移动。

逐件测量、逐件建模不现实。可行的做法是随机化：仿真里生成的包裹分布足够宽，能把真实情况包在里面，策略就不会只适应某一种包裹。项目因此希望建立一个可批量生成物体的模型，通过换参数覆盖这些差异，支持后续策略学习。

当前需要回答的研究问题是：**少量与抓取相关的整体响应，能否构成足够有效的随机化空间，并帮助策略泛化到未见过的真实软包？**

## 2. 统一建模表达：A = X · B

**A = X · B** 表达的是“共用模板，通过换参数生成不同物体”的建模方式：

| 符号 | 含义 | 在本项目中的内容 |
|---|---|---|
| B | 所有软包共用的建模模板和力学规则 | 内容物的分段生成规则、弹性关节规律、外层袋子模型、接触与摩擦规律 |
| X | 描述一个物体的参数，对应参数向量 κ | 尺寸、质量、质心、夹紧与下垂响应、袋子性质、摩擦，以及段数和锁死开关等离散选择 |
| A | 由 X 实例化 B 得到的具体软包模型 | 具有某种形状、重量和抓取响应的训练物体 |

这里的“·”表示参数作用于模板的生成过程，实现时可以写作 **A = g_B(X)**。B 固定的是生成规则与力学形式；段数等变化由 X 控制。物体参数 X 只放物理量，与步长、迭代次数等求解器配置分开，后者所有物体共用一份。

**重参数化**：在不受约束的空间里随机扰动，再映射回 X。必须为正的量用指数映射，必须落在区间里的量用 sigmoid，袋子尺寸由内容物尺寸导出。这样抽到的每个物体都满足基本约束，不会出现负刚度、袋子装不下内容物这类情况。参数组合是否可实现、能否稳定仿真，仍要靠扫描验证。

方法借鉴 [XHugWBC §3.1](https://arxiv.org/html/2602.05791v3#S3.SS1) 中“模板 + 物理一致参数化 + 随机化”的思路：它用一个模板机器人加参数随机化，让一个控制器零样本迁移到 7 种人形机器人。论文研究的是跨人形机器人控制，本项目中软包响应空间的有效性需要独立验证。

预期的完整流程如下，训练与实物评估属于后续阶段：

**采样目标响应与物体参数 → 生成分段内容物与外层袋子 → 检查响应、稳定性与成本 → 构造随机化抓取训练环境 → 评估未见真实软包。**

## 3. 模板 B 如何实现

一个软包由三部分描述：**内容物、外层袋子、二者之间的接触与摩擦**。实际包裹有满装也有松装，末端只用平行夹爪。第一版对两种情况区别处理：

- **满装包裹**：袋子基本是一层有摩擦、可能稍软的外皮，它的效果（表面摩擦、气泡缓冲、纸板刚性、重量）并入内容物的等效外皮参数，整个包裹当成一个物体；
- **松装包裹**：袋与内容物之间的相对滑动、夹到空袋、提起袋角，这些并不进内容物，需要单独的袋子表示。现有薄壳袋子模型（四种袋子共用一套方程）作为参考，用对比实验决定采用哪种更便宜的表示。

内容物采用同一套分段结构，通过参数生成不同响应。

内容物被划分为若干长方体刚体段，相邻段用带弹簧、阻尼和限位的关节连接，思路类似把机器人简化成连杆和关节。平移自由度负责等效压缩和剪切，转动自由度负责弯曲和扭转。关节锁死时，整体表现为硬物。每段的质量和惯量由尺寸和质量份额直接算出，天然满足物理一致。

| 第一版行为类别 | 夹紧时 | 提起时 | 对应物品示例 |
|---|---|---|---|
| 硬物 | 压缩很小，很快顶住 | 保持形状 | 书、硬盒 |
| 易弯物 | 有一定夹紧变形 | 明显弯折、下垂 | 叠好的衣服、毛巾 |
| 易压物 | 容易压扁，压到一定程度后顶住 | 允许一定下垂 | 枕头、揉团衣物 |

这些是目标行为类别，尚未由新模型实现。第一版接受长方体包络、粗分段和相邻段重叠，以重叠近似压密；外部接触、夹持反力与抓取结果需要验证。活动质量单元可用于近似内部晃动，默认关闭。迟滞、蠕变和精细形状变化按后续任务需求加入。

**为什么选这种结构**：此前试过另外两种内容物表示，都在夹取场景下暴露了问题。

| 方案 | 结论 | 依据 |
|---|---|---|
| 分段刚体 + 弹性关节 | 采用 | 参数和行为基本一一对应；刚体接触稳定；自由度少，以后批量训练更快 |
| 四面体软体 | 搁置 | 刚体压上去会持续抖动；软材料在指垫角下单元翻转；接触区网格加密后反而更早翻转 |
| 粒子 + 键 | 停止 | 揉团和枕头受压像沙堆一样塌，压缩特性的标定不收敛 |

## 4. 参数 X 直接对应夹爪感受到的响应

参数向量分为内容物、袋子和界面三组。内容物的关键参数用固定动作下可测的整体响应定义：

| 参数组 | 代表量 | 对任务的意义 |
|---|---|---|
| 几何与质量 | 尺寸、总质量、质心偏移 | 夹持位置、承重需求、搬运力矩 |
| 夹紧响应 | 侧向与厚度方向的等效夹紧刚度 | 合拢多少、需要多大夹持力 |
| 压密响应 | 顶住时的压缩比 | 容易压扁到什么程度 |
| 提起响应 | 提起下垂比 | 夹持后能否保持形状 |
| 动态响应 | 阻尼比、可选活动质量 | 摆动、急停和滑脱 |
| 等效外皮 | 表面摩擦系数、可选的外皮柔度 | 满装包裹中袋子带来的摩擦和缓冲 |
| 袋子与界面（松装） | 膜与弯曲性质、袋与内容物的摩擦 | 隔袋传力、袋与内容物的相对滑动 |

每个响应量都由固定测法定义：夹紧（两侧指垫合拢，取压缩 5%–15% 的割线刚度）、提起（夹住短边中点提起，量远端下降与长度之比）、搬运（夹起后水平加速再急停，量滑移和摆动）。仿真和实物用同一套测法，所以随机化的范围可以直接和实物粗测对应。

模型内部将目标响应换算成关节参数，计划先用解析估计，再通过仿真扫描建表修正。**这套换算尚未建立，能否稳定命中目标响应是首轮要验证的问题。**

段数可以随机，但相同目标响应在不同段数下应当接近；段数主要改变局部细节与计算成本。段越细越贵：段尺寸减半，稳定步长大约也要减半。

## 5. 目前有什么基础

| 部分 | 已有结果 | 当前边界 |
|---|---|---|
| 外层袋子 | 已有 PE、牛皮纸、纸板、气泡袋四类参数配置；Newton 后端第一阶段完成 | 自接触、材料历史效应和速度仍有问题；全部未经实物标定 |
| 袋内刚体静置 | 已测试装入刚体后静置 1.5 秒，受测内容物均留在袋内、未发散 | 纸板装书仍明显晃动；静置结果尚未覆盖隔袋夹取与搬运 |
| 接触诊断 | 查清了 Newton 中刚体压四面体抖动的根因：平的刚体压在平的边或面上时，接触点在两端之间来回跳。按覆盖面积积分的修法在平压基准上通过，支撑力误差 0.001%–0.02% | 修法只支持竖直平面工具压顶面；同类问题可能出现在长方体压袋膜时 |
| 夹爪测试 | 位移控制的夹爪能夹起硬海绵，质心升高 92%–95% | 软海绵翻转或滑脱；这是四面体路线退出的依据之一 |
| 旧内容物路线 | 粒子模型、四面体和接触诊断积累了代码与基准 | 两条路线已退出关键路径 |
| 新分段方案 | 已形成模型设计、参数规格、响应测法和首轮测试计划 | 尚未实现，尚无稳定性、吞吐或迁移结果 |

现有袋子单环境速度约为 **0.012–0.058 倍实时**，来自袋子线的既有测试；新分段模型和完整软包的批量吞吐尚无数据。速度是后续训练能否落地的重要约束。

## 6. 如何用最少的实验判断方案是否值得继续

**第一步：只测内容物。** 用同一套夹紧、提起和搬运动作，验证三类响应能否区分、参数改变时响应是否可控，并记录单环境和批量成本。首轮计划：随机扫描 200 组参数，样本内失败率目标不超过 1%；响应命中误差暂定不超过 20%。这些是原型阶段的检查标准，不能直接代表真实任务成功率。

**同时：量化袋子的影响。** 用现有袋子模型装硬盒，在满装和松装两种情况下，与“不装袋、只用袋子材料摩擦的硬盒”比较夹紧、提起、搬运的结果，确认满装时并入外皮是否成立、松装时差别有多大；再在 MuJoCo 里试两种便宜的松装袋子表示（flex 薄膜、薄板片），比较行为和速度。

**第二步：松装包裹。** 用选定的袋子表示装入分段内容物，检查隔袋夹紧、提起和搬运，确认关键响应保留且接触稳定。

**第三步：与实物对照。** 选 3–5 件代表物品，用相同脚本化动作比较夹持力、下垂、相对滑移和掉落情况，判断哪些近似需要修正。

**路线是否有效的判断。** 后续训练评估建议由组会讨论确定：在相同袋子、策略和训练预算下，比较“只随机尺寸、质量和摩擦的刚体内容物”与“增加分段响应随机化”的效果，重点记录未见真实物品的抓取成功率、搬运掉落率和训练成本。该对照尚未执行，重复次数和具体预算待定。

在训练之前，可以先做一个不需要策略的版本（建议）：用脚本化抓取，比较两种随机化在夹持力、下垂、滑脱、掉落上的结果分布，能覆盖多少真实物品的表现。如果只随机刚体已经能覆盖，分段模型的必要性要重新考虑。

实现上，内容物先用 MuJoCo 适配层验证，同时检查 Newton VBD 能否求解闭环的关节网格；构建代码与引擎无关，换平台时只换适配层。

## 7. 主要风险

| 风险 | 说明 |
|---|---|
| 平台未定 | 第一版不单独建袋后，内容物只是刚体加关节，平台倾向 MuJoCo / MJWarp。松装包裹若需要膜表示，候选是 MuJoCo flex 薄膜或 Isaac Lab 3.0 的 MuJoCo-Warp + VBD 耦合方案；后者的耦合是实验性的，能否按环境随机化参数、每个环境结构不同能否一起跑，文档都没写明 |
| 速度 | 单个袋子 0.012–0.058 倍实时；建模阶段够用，大规模训练前必须解决 |
| 松装包裹 | 必须覆盖（目标投稿 RSS 2027）。袋子表示待对比实验选定；现有袋子几何是每种袋子一个固定网格，尺寸不能随内容物变，膜刚度在步长受限时会被自动软化，需要先补参数化几何 |
| 膜表示的接触 | 若松装采用膜表示，刚体压在膜节点之间可能出现与四面体相同的接触点跳动，需在采用前确认 |
| 随机范围无依据 | 所有参数都是设定值，没有实物标定；需要按响应测法粗测几件最软、最硬的典型物品来定上下界 |

## 8. 希望讨论和决定的事项

1. **行为覆盖是否够用？** 硬物、易弯物、易压物，加上质量、质心和摩擦变化，是否覆盖首轮分拣任务的主要难点？
2. **第一版任务边界是什么？** 是否先以单袋单件、长方体近似验证，散件、多件和复杂外形后续再扩展？
3. **最小实物验证怎么选？** 哪几件物品最有代表性，哪些观测最能揭示模型遗漏的抓取机制？
4. **怎样判断这条路线有效？** 是否接受上述刚体随机化基线，以及以真实抓取表现和计算成本共同评估？
5. **松装包裹的优先级**：松装在实际包裹中占多少？若比例高，袋子表示要尽早做；若需要膜表示且 MuJoCo 不够用，再考虑单独安装 Isaac Lab 3.0（需要 Isaac Sim 6.2、PyTorch 2.11、CUDA 13.0）试跑耦合方案。
