# Policy V3-MVP 软件验证

## 2026-11-25 本轮计划

- C0 使用一个固定临时刚体与 Yam_B，检查实接触闭合、提起、搬运、释放和入篮。另在原生 MJWarp 入口做一次单卡刚体和一次 PE Flex 接线检查，在 `ubun` 上持共享锁执行。
- C1 先用 100 个独立随机初始态检查采集，再用 1,000 个初始态检查同一入口。每个 Try 执行一次抓取，统计成功、普通失败、无效及其原因。
- C2 用上述分组数据运行一次 BCE 软件预训练。通过标准是训练 BCE 下降，独立验证集报告候选排序指标或明确记录排序所需的匹配标签缺口。
- C3 运行一次 PPO 更新，检查动作和 critic 参数更新及数值有限。用两个隔离的 CPU 子进程模拟 GPU Worker 并发，验证屏障、规则与权重版本及种子隔离。C4 增加一次交替更新接口测试。
- 单测检查冻结路径、视觉读取边界、分组交叉及传递闭包、物理无效分流和 pre-tanh 边界。关键检查失败则定位并记录，全部通过则交付软件流程及适配边界。

### 结果

主机 `ubun`，CPU 使用 MuJoCo 4.0.1 和 PyTorch 2.15.0+cpu。单卡使用 RTX 5090、MJWarp 4.0.1 和 Warp 1.19.0。以下命令均从仓库根目录运行，设置 `PYTHONPATH=src:experience:.`、`OMP_NUM_THREADS=2` 和 `OPENBLAS_NUM_THREADS=2`。可复查数据见[运行目录](../runs/2026-11-25/policy/policy-v3-mvp-r1)。

| 检查 | 结果 |
| --- | --- |
| C0 刚体 | CPU 和单卡 GPU 均通过实接触抓放。GPU 使用外表面分割和深度，载荷净抬升 126.58 mm，提起过程中 24 帧双侧指垫接触。 |
| C0 PE Flex 浅试探 | 51 帧有效历史，完成统一悬停撤回并取得 `v1` 深度几何。当次峰值机器人接触力为 0 N。 |
| C0 PE Flex 深试探 | 接入 142 节点 PE Flex、原生 Yam_B 和外袋深度观测。产生 22 帧有效历史，峰值接触约 4.87 N。检测到穿透超限后停止，标记 probe 无效并跳过撤回与 `v1`。 |
| C1 100 回合 | 最终两 Worker 运行有 46 回合物理有效，11 正样本、35 BCE 负样本、54 无效。78 回合采到非空 Try 历史。 |
| C1 1,000 回合 | 519 回合物理有效，113 正样本、396 BCE 负样本、10 回合没有可用于 BCE 的抓取。481 回合因穿透超限无效，其中 probe 60、grasp 421。 |
| C2 1,000 回合数据 | 20 epoch 后训练 BCE 由 0.6848 降至 0.3290。验证 AUC 0.6362，匹配状态排序为 4/6。测试 AUC 0.6030，匹配状态排序为 5/7。 |
| C3 两 Worker | 两进程各自独立种子和缓存目录，按版本 1 的共同校验和完成采样。16 条回合中剔除 5 条物理无效样本，11 条用于 PPO。actor／critic 损失 −0.1952／0.6075。 |
| C4 两 Worker | 12 回合中 7 条进入 PPO，接着对累计 Replay 做一次 BCE，保留 C2 的分组归属并发布版本 2。 |
| 默认候选数 | 共同世界工作空间检查通过，生成 256 个不同候选，相对中立接近方向倾角约 1.0°–72.0°。 |

最终两轮数据均保留 48D `H_try` 与 54D `H_try_raw`。两轮使用不同种子。50／500 组分别包含两个独立复位后重演的回合，每次 Try 只执行一次抓取。物理无效率与有效匹配对的数量限制了结果的解释范围。

CPU 实接触回归确认 0.31 N·m 力矩设定按浮点传动比生效。修复此前整数裁剪，以及小训练集单样本尾批易主导 Adam 更新的问题后，100 回合烟测训练 BCE 从 0.6870 降至 0.3388。另用 8 回合运行共享世界候选到 J00 的训练入口，样本仅包含负标签，记录入口通过。

复现入口见[Policy V3 README](../../src/policy_v3/README.md)。调试日志保留了单测夹具缺字段、一次 BCE 未下降，以及 Flex MJCF pad 顶点格式和 flex ID API 错误。


PE Flex 首次复位时，有限盒状桌面的薄膜接触达到约 4.4 mm 穿透。改用现有 PE 平面接触模型承托薄膜，ABC 盒状桌面用于刚体碰撞，随后复位与外袋深度观测通过。第一条居中轨迹靠近篮壁，静态预筛拒绝。移至工作区内的深轨迹后触发穿透保护，随后按 1 mm 穿透门槛通过浅试探、正常撤回及撤回后相机采集。[复位诊断](../runs/2026-11-25/policy/policy-v3-mvp-r1/flex-reset-diagnostics.log) · [深试探历史](../runs/2026-11-25/policy/policy-v3-mvp-r1/flex-probe/)
