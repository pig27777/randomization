# Yam_B 纯仿真机器人验收

## 首轮计划

使用统一抓取平台内的 Menagerie linear_4310 资产，沿用 ABC Yam_B 安装位姿与 14.4 × 16.4 mm 指垫。新增入口独立配置控制和观测，以检查 SDK 的有限刚度与可部署反馈语义。旧抓取协议及其阈值沿用原配置。

| 检查 | 配置与重复 | 通过标准 |
| --- | --- | --- |
| A 空载跟踪 | 关节逐轴和小幅 6D 末端动作，各 1 次 | 逐轴响应方向正确，最后 0.4 s 关节最大指令误差低于 0.05 rad，无持续振荡、越限或 >5% 的力矩饱和步，末端能沿指令方向平移及旋转 |
| B 接触反馈 | 空载、软接触、硬接触各 1 次，同一慢速下压关节轨迹 | 软、硬两次均出现原生接触，力矩/跟踪误差/速度轨迹与空载可区分，反馈对应实际执行器输出 |
| C 夹爪 | 空夹和刚体各 1 次 | 空夹最终 ≤2 mm；物块限制开度且实际努力增加；力限生效，松开后失去双指接触 |
| D 刚体抓放 | 1 次 | 双指原生接触，以物块离台 ≥40 mm 验证提起，搬运 ≥80 mm，松开后落入目标托盘并静止 |
| E/F 整袋 | 有通过无旁路门槛的袋体后，各工况 1 次 | 同轨迹左/中/右本体响应不同，薄膜抓和隔袋抓均实提实放，无明显穿透、直接内芯接触或重复传力 |
| G GPU | N=1/16/64，条件允许 N=256，各 1 次，先 nominal 后 DR | CUDA 控制、观测、历史与选行重置均生效，复核随机参数实际影响动力学，无非有限、容量溢出或跨环境串扰。预热后记录吞吐和 NVIDIA 进程显存采样峰值 |

A–D 或 G 不通过时修复可复现的机器人接口或数值问题，再复跑受影响项。E/F 门槛不通过时回链已有证据，保持待验。所有正式运行在同一机器持 `/tmp/claude-gpu.lock`。

### 整袋接入补充计划

袋体线的 142 节点 PE 在 200 μs 的 GPU 主动接触夹具中通过，GPU 隔袋稳持仍未通过。在同一 PE 参数上通过模型适配器试一次完整 Yam_B 接触入口和三路 Try。外袋 x/y 参考坐标固定，0.20 kg 内芯的 x 初位为 −55/0/+55 mm。三路使用同一自由空间离线 IK 生成的下压和短扫指令。保留真实外壳—内芯碰撞对，以能检测实际旁路。最低通过标准为三路持续膜接触至少 20 ms，至少两两相隔 0.03 Nm 的峰值六轴 effort 向量差，膜或台面几何侵入 ≤2 mm，零机器人—内芯载荷及容量溢出。仅当接触入口及现有袋体的稳持门槛都通过才执行 F。

首次整袋入口沿用更长的 120 mm 短扫，三种内芯分别启动模型。后续改为同一已编译模型的三路批量试验，通过设备批量初态写入各自的预包覆位置。为控制烟测耗时，扫描行程收为 76 mm，总时长 2.64 s。接触持续时间由 25 Hz 连续采样帧之间的跨度估计。验收阈值沿用补充计划。

首个顺序左位回合检测到 17.13 N 直接内芯接触。按失败门槛停掉该批余下两路，保留左位原始轨迹。批量复验使用同一名义外袋、0.012 m 开度和自由空间 IK 起始位，先在预备高度静置，再把扫描目标提高到 39 mm，以保留与内芯顶面之间的物理间隙。改用刚体局部坐标核对盒子几何，避免凸网格在编译时的主轴重排影响判断。复验共 1.84 s，原接触门槛保持。

### ABC 工作站复验计划

直接加载已有 Route B ABC 场景配置，保留桌面、620 mm 双基座间距、顶相机和右腕 D405 帧。Yam_A 使用共享 CAD 与工作站的停驻角，作为固定的可碰撞场景几何。Yam_B 使用原六轴控制器。检查两个基座、桌面高度、相机帧和执行器数，再执行一次相同的 C/D 抓放及回放。

## 纯机器人与刚体结果

机器 `ubun`，RTX 5090（32,607 MiB），MuJoCo/MJWarp 3.17.0，Warp 1.19.0。GPU 正式运行均持共享锁。默认统计 1 ms 物理步、250 Hz 电机与传感更新、125 Hz 目标插补和 25 Hz 动作。 [R4 原始结果](../runs/2026-11-25/yam/pure-sim-r4/)

| 检查 | 状态 | 证据 |
| --- | --- | --- |
| A 空载跟踪 | PASS | 六轴分别正向约 0.138–0.151 rad。末窗最大误差 0.00969 rad，末窗运动范围 0.00622 rad，力矩饱和和关节越限均为零。笛卡尔指令产生 +38.52 mm x 位移与 +0.02770 rad z 旋转。 |
| B 等轨迹软硬接触 | PASS | 空载、等效弹性试件及刚体的原生接触峰值为 0、11.17、19.72 N。任意两工况的峰值六轴 effort 差为 2.98–6.71 N·m。跟踪误差与速度均不同。名义反馈与实际施加力矩逐帧相等。 |
| C 空夹、刚体夹持及释放 | PASS | 空夹开度 0 mm，52 mm 试块将实际开度阻在约 50.84 mm。堵转等效反馈约 −0.731 N·m，达到 50 N 限幅，释放后双指失触。 |

| SDK 字段与轴向 | PASS | 本地顺序、方向、角域和 SDK v1 XML 相符，实测仿真 SDK 编解码尺寸为 28。 |

| 真机通信与物理标定 | NOT TESTED | 保留离线字段映射，现场机械零点、TCP、力矩和时间核对留给部署阶段。 |

B 的软试件使用原生接触驱动的 900 N/m 单自由度垂向弹簧、8 N·s/m 阻尼和与硬对照相同的上表面。试件和执行器均由动力学求解。G 的同动作路径在名义同组环境重合，DR 同组的实际 TCP 路径分开。重置时读取质量／惯量同倍率、摩擦、armature 和指垫摩擦变更，非重置行状态和观测维持原值。延迟的 q 和 effort 与指定旧传感帧逐元素相符。

每配置先热身 5 个策略步，再计 60 个策略步。每步包含 CUDA IK、40 个物理子步、反馈及历史，用环境数乘过的总步数除墙钟时间。显存为运行期间 NVIDIA 进程占用抽样最大值，各配置数值故障与容量溢出均为零。性能表使用无袋体、无渲染的工作台测试。

R1 初次抓放触发 64 行约束缓冲不足，改为 256 行后通过。首轮 G 测试输入只有六列，被七维接口拒绝。修正测试并增加真实队列帧校验后通过。R2 的混合延迟行暴露 float32 时间相减容差，R4 改从传感队列直接读对应时间戳，并以 ≤8 μs 的容差核对物理时钟累计误差。

39 mm 批量复验三路包覆均保持，有限状态和缓冲均正常，未压到膜。用已保存网格复算，膜最高处 26.0–26.3 mm，而该扫描的指垫底缘在约 31 mm。最后一次仅把扫描指令降低到 34.7 mm，目标落入膜面与内芯直触之间的候选窗口，沿用三路批量和相同验收标准。
