# 2D flex 薄膜＋自由颗粒速度实验

## 本轮计划（2026-11-09，机器 ubun；运行前登记）

问题：封闭薄膜加自由颗粒，在现有 MuJoCo 3.17 / MJWarp 3.17 环境中的步进成本和批量吞吐是多少？本轮不运行机械臂或完整抓取，不改袋子、内容物与策略线代码。

- 几何：240×180×160 mm 封闭矩形袋壳，立方体表面规则三角网格，4/6 段每边，分别 98/218 顶点、192/432 三角面；袋质量 12 g。预设鼓形为参考形状，没有气腔或保体积项。
- 材料：原生 `dim=2`、`elastic2d=stretch`，E=5 MPa、厚度 0.2 mm（Et=1000 N/m）、泊松比 0.3、Rayleigh 阻尼 1e-4 s；不含弯曲、塑性或撕裂。开启 `selfcollide=auto`。这是未标定的理想薄膜，不宣称等同 PE 实物。
- 颗粒：64/216/512 个无连接的自由刚体球，半径 8 mm、密度 600 kg/m³，初态格点间距 17.5 mm；颗粒间、颗粒与袋膜均有摩擦接触。地面只接触袋膜，不能越膜直接支撑颗粒。
- 数值：CPU/GPU 使用相同模型、CG、迭代上限 100、容差 1e-6、步长 0.5 ms、接触时间常数 5 ms、椭圆摩擦锥、滑动摩擦系数 0.5；初始袋底距桌面 2 mm，重力落袋并发生颗粒重排。
- 首先 CPU 20 步入口，再做 98 顶点×三种颗粒数各 0.3 s；216 粒另做 218 顶点。每配置先一次；通过才测 GPU 1/32 环境，较合适配置再测 128 环境。完整计时重复 3 次，同初态重建，取中位数；入口/失败配置不重复堆测。
- GPU 编译、上传、图捕获和独立预热不计入步进时间；正式状态从干净初态重建，CUDA 图每块 20 步。报告物理步进与内置诊断耗时，以及另计的 CPU 几何检查开销，不换算成抓取次数/s。
- 正确性门槛先固定：有限状态、CPU 无 warning、GPU 原始 overflow 累计为零；采样接触穿透≤1 mm；每 10 ms 检查颗粒中心在闭合袋内，且球面超出袋膜中面不超过 1 mm。GPU 每步累计有限性/overflow/接触穿透，几何至少查代表环境的时序及所有环境终态。未做独立线性求解残差验收，迭代触顶单列；不宣称 CPU/GPU 轨迹等价或训练已可用。
- 正式 CPU/GPU 测速均使用 `flock /tmp/claude-gpu.lock`；GPU 上限依 CPU 实测接触/约束行峰值×1.5 设置，留最低容量；溢出配置作废，记录后单独增加容量复测。新目录保存 XML、源码哈希、JSON 和日志。

通过后报告规模与速度关系；若几何或数值不通过，先隔离入口问题，保留失败证据，不用失败配置的速度作有效吞吐结论。

## 结果

入口首试：本机 3.17 XML schema 不接受 flex/contact 的 `internal` 属性；删除该不支持的属性，保留 `selfcollide=auto`，未改变数值或几何验收门槛。首试未进入物理步进。

64 粒、98 顶点原接触 5 ms 配置在第 220 步检查失败：状态有限、无 warning、颗粒中心均在袋内，但接触峰值穿透 3.486 mm，球面越过中面 1.308 mm；CG 峰值 100 次。速度无效，不重复三次。为抑制落袋冲击的接触压入，下一试只把接触时间常数从 5 ms 改为 1 ms（2 个步长），其余参数与 1 mm 门槛保持；后续 JSON metadata 显式记录。原结果保留 `cpu64_mesh98.json`。

### CG 诊断与 Newton 对照追加计划（运行前）

1 ms 接触下四组 CPU CG 的几何/有限性检查均通过、各完成三次，但均达到 100 次迭代上限。GPU 64 粒单环境在 0.11 s 出现原始 overflow=512；源码 `OverflowType.ITERATIONS=1<<9`，这是求解迭代触顶，不是容量不足，接触/约束峰值 91/273 小于 256/512。该 GPU 配置不通过，不扩批，不把原始标志屏蔽为零。

CPU CG 原 JSON 的 `valid` 只涵盖当时 CPU 几何/有限性门槛，不代表已收敛，CPU/GPU CG 数字均只留作诊断。下一轮唯一方案变更是 CPU/GPU 同改 Newton；维持 1 ms 接触、100 次上限及其余数值、几何参数，按原四个几何配置先 CPU 再 GPU 1/32、合适配置 128，每配置三次。CPU 也增加“未触顶”检查，与 GPU 原始 overflow=0 对齐，标准只收紧不放宽。若 Newton 仍不通过，停止扩批、报告阻塞。入口与正式运行沿用同一 GPU 锁。

### Newton 正式结果（2026-11-09 16:22 +08:00）

CPU 四组、GPU 64 粒单环境均各完成 3 次 600 步（0.3 s），下表取中位数；均有限、颗粒中心采样时未出袋、球面越膜≤1 mm，CPU 无 native warning、外层求解未触顶，GPU 原始 overflow 累计为零。RTX 5090（32 GB），同一台 ubun，均持 GPU 锁。实时率为仿真时长/步进墙钟时间，1 表示实时。

| 后端 | 膜顶点/三角面 | 颗粒数 | 速度自由度 nv | 环境数 | 0.3 s 步进耗时 s | 环境步/s | 单环境实时率 | 包含几何检查的总耗时 s |
|---|---|---:|---:|---:|---:|---:|---:|---:|
| CPU Newton | 98/192 | 64 | 678 | 1 | 1.206 | 497.59 | 0.2488 | 1.339 |
| CPU Newton | 98/192 | 216 | 1590 | 1 | 3.321 | 180.69 | 0.0903 | 3.773 |
| CPU Newton | 98/192 | 512 | 3366 | 1 | 10.196 | 58.85 | 0.0294 | 11.304 |
| CPU Newton | 218/432 | 216 | 1950 | 1 | 11.652 | 51.49 | 0.0257 | 12.721 |
| GPU Newton | 98/192 | 64 | 678 | 1 | 29.812 | 20.13 | 0.0101 | 29.924 |

上述五组接触峰值穿透分别 0.846/0.762/0.671/0.758/0.865 mm；外层求解峰值迭代 13/17/21/19/14。CPU 每步计时包含 Python 接触/约束/迭代计数，GPU 包含 CUDA 图启动、同步、逐步有限性/原始标志/接触深度统计；CPU 几何检查与 GPU 读回/几何检查单列，不把这些数字称为无诊断的物理引擎上限速度。GPU 初始化、独立预热、上传及捕获单列，三次 setup 为 1.903/0.211/0.211 s。

**批量停止结果**：64 粒、98 顶点、32 环境 Newton 在第 220 步（0.11 s）出现原始 overflow=1024=`OverflowType.LS_ITERATIONS`，即 20 次线搜索上限；外层迭代峰值 8，峰值接触总数 2912、每环境约束峰值 273，均未超过接触/约束容量（256/512 每环境）。状态有限、采样几何通过、接触峰值穿透 0.865 mm，但未满足零原始标志门槛；7.059 s 是失败前诊断耗时，不能作为有效批量吞吐。按预写停止规则不重复该失败配置、不扩 128，也不继续更大颗粒/网格 GPU 批量。未降低精度、屏蔽求解标志或放宽几何标准。

**规模判断**：同一粗膜下 CPU 64→512 粒耗时约 8.46 倍；216 粒将膜顶点从 98 加到 218，耗时约 3.51 倍。当前 Newton 实现下，GPU 单环境没有体现加速，32 环境尚未获得可用吞吐；不能外推为所有薄膜/颗粒求解器都慢。CG 诊断较快但触顶，不与已通过的 Newton 表混为可用性能。

**动态确实执行**：CPU 三种颗粒数的最大水平位移约 33.2/50.7/62.2 mm，平均下降约 60.4/60.4/51.9 mm。颗粒均无关节连接；地面碰撞位只允许接触袋膜。该预设鼓形粗壳终态包络体积约 6.84/7.02/7.38 L，并非经过标定的真实袋内填充形态。
