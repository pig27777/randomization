# 随机袋装包裹模型

## 本轮计划 2026-11-14

机器 ubun，MJWarp 3.17.0、Warp 1.19.0、MuJoCo 3.17.0，RTX 5090。

本轮实现候选模型，以单刚体和三段转动关节两种拓扑分批。先验证内容物，再加入三路径袋体、有限摩擦滑移与一次闭合捕获。所有随机范围是工程假设。

- 解析与 GPU 核测试各一次，验证质量惯量、响应映射、材料守恒、事件只采样一次、力和力矩守恒、滑移和破坏状态、reset 可复现。容差浮点量 1e-5，相对力矩 1e-4。
- 六原型各 8 环境，静置、接触压缩、回弹、承载夹具、偏心与低摩擦测试各一次。检查有限状态，静置末速度 <0.02 m/s，穿透 <5 mm，初始张力为零。步长 0.5 ms，并对承载做 0.25 ms 对照，主要位移差 <5 mm。
- 随机压力测试每拓扑 512 环境 2 s，极值配置各 8 环境，无 NaN/Inf、非法惯量或失效后残余张力。
- N=1/64/512/2048/4096，对 payload/bag/full 各测一次，先 warmup 再同步计时，记录真实显存、CUDA Graph 和吞吐。

通过后整理运行入口、参数单位、曲线和适用范围。失败时定位根因并保留记录，未经运行的项目标为待验证。机械臂动作沿用 experience 平台，模型本构夹具仅验证材料响应。

### YAM 平台补充计划

按用户要求，六原型各 1 次运行共享 YAM v2.2 完整动作，0°/0°、seed=7、dt=0.5 ms。独立夹具只记为材料/数值测试。YAM 记录原平台的 success/grasp_fail/setup_fail 等结果及力、穿透、轨迹，不调整既有判据。适配器使用同一 Warp 力核的 CPU 执行进行机器人验证，GPU 并行当前为模型批次，尚未将整台 YAM 纳入 GPU 异构批次。入口检查通过后运行完整动作，失败保留原始原因。

### YAM 捕获接口修正

固定 v1.3 聚拢弹簧导致新模型在大间隙提前结束闭合。公共协议增加可选适配器聚拢弹簧接口，默认行为保持原实现。新适配器按已有聚拢材料长度提供法向接触代理。代理宽度为 `min(0.004+2*材料长度,0.024)` m，每指刚度 10000 N/m、阻尼 2 N·s/m，形成真实手指反力。材料预算不足时代理力为零。动作和验收阈值未改。此前固定 4 mm 代理在捕获较宽聚拢层后丢失法向力，修正后重跑 YAM 与材料测试，旧失败结果保留。

## 六面封闭薄膜修订：本轮计划 2026-11-14

用户指定最小六面物理包络，先验证原生接口，再接入。采用每面3×3、边界共享的封闭三角网格，共26个物理节点、48个三角形，六面共享边角。优先复用MuJoCo/MJWarp原生flex的三角面碰撞与节点动力学。安装版本支持dim=2原生碰撞，但flex_stiffness/bending/rest/friction字段不支持逐环境批量，因此面内/弯曲能量和断裂用Warp维护逐环境数组，原生膜弹性禁用；摩擦由相邻geom的逐环境参数确定。原生flex用于实际碰撞，节点具有独立正质量。

- 先以单刚体和三段内容物各1环境检查原生dim=2碰撞/step/capture入口。膜开启时删除原三路径力和聚拢夹持代理，内容物与桌面/手指的裸核心直接接触禁用；唯一承载链为手指接触→膜面张力/弯曲→内容物接触。
- 拓扑、六面法向/接缝共享、质量面积一致性、能量梯度、总力/力矩、刚体变换客观性、阻尼耗散、材料预算与换面守恒各检查1次。能量梯度相对容差1%，净内力/力矩相对1e-4；无损膜每边恰好两相邻三角形。
- 六面各进行1次接触探针测试，法向载荷>0且负载经膜传递。底面静置2秒，膜—桌支撑应覆盖重量的95%–105%，裸核心—桌面接触必须为零。满/松包络初态均无严重穿透（<接触padding的2倍），内容物必须处于闭合膜内。
- 共享YAM同一原型3/seed7、顶面和侧面各1次，保留原动作/判定；失败按实际记录。侧面沿用已可达的30°向下接近，不筛选种子。六面覆盖不等于六种方向YAM均可达，底面材料检查采用旋转后的探针场景。
- GPU以固定拓扑逐环境更新位置、质量、惯量与参数，N=1/64先验，再按显存与实际稳定性扩至512/2048/4096；先warmup/同步后计时，正式GPU持flock。步内无逐环境Python循环，CUDA Graph实际capture/replay验证。静置/受扰运动检查NaN、支撑、边伸长与穿出情况。未验证的规模或动态场景单列。

通过后记录物理方程、配置单位、六面拓扑图、接触关系与GPU限制，失败保留诊断并修复根因，不以放宽阈值制造通过。

3×3原型结果：六方向探针均产生膜接触反力，净内力/力矩约1e-9，能量梯度相对误差0.0169%，刚体旋转能量差0.000964%。但刚性原型2秒静置仅约6%重量仍经底膜支撑，内容物角点穿出；柔性满装也有1角点穿出。保持支撑/包覆标准，分辨率改为每面4×4（56共享节点、108三角形），重跑同样检查。这是最小网格分辨率的修正，未增加核心—桌面直接碰撞或核心焊接。

4×4检查显示刚性重量支撑恢复，但满装三段原型仍穿出。发现原核心沿x只有单元长度的98%，存在段间空缝，4×4膜底节点恰落在这些空缝附近。膜模式将核心与压板的x碰撞尺寸恢复到完整单元宽度（惯量原本也按完整单元计算），相邻内容物仍按原约定排除碰撞。此修正只用于显式膜模式，原历史效果模型几何保持原值。另对比discrete/CG与implicitfast/Newton，两者均复现满装穿出，因此不把原问题归咎于积分器。碰撞专用flex无原生膜弹性，允许implicitfast，后续使用implicitfast/Newton以沿用内容物隐式阻尼并避免非批量efm0常量对异构弹性的限制。

完整单元核心消除静置无约束穿出，六原型支撑恢复至重量的99.96%–100.04%，裸核心—桌面接触均0。中面winding仍显示若干角点越界，测得最大距离1.23–4.13mm，超过1mm接触padding，因此不认定包覆通过。对膜—内容物和膜—桌面接触采用有限1ms时间常数、0.99阻抗，以降低轻膜节点与重内容物之间的数值接触压缩；YAM手指仍沿用平台接触配置。接触数值参数变更由薄层不可穿透要求驱动，支撑和包覆判据不变。候选缓存从256增至1024以消除已观测到的flex候选溢出，后续同时检查overflow位图。

GPU首次完整测速已通过单刚体N=1/64/512/2048，4096在原生flex EPA工作区分配时显存不足。安装API允许把接触候选容量nconmax与CCD/EPA容量nccdmax分别设置；原先两者均为1024/环境，预分配过多EPA缓存。保留1024接触候选，将CCD/EPA容量改为256/环境，所有规模继续检查CCD/候选/约束overflow位图，若溢出则判失败，未减少碰撞或关闭自碰撞。

### 降回弹修订补充计划

固定局部细化56节点拓扑、原型3/seed7，对旧参数与新参数各做一次隔离自由回弹试验，重力与外部接触关闭，顶面四个内部节点初始抬高5mm，dt=62.5μs、1秒。记录含动能的总机械能、材料耗散功率、去质心顶面位移。工程通过标准为新参数末端归一化机械能低于旧参数、全程有限，耗散力功率非正，净力/力矩和刚体运动客观性保持原标准。7项本构/预算测试各一次。该对照同时改变拉伸刚度与两种阻尼，用于验证组合修订。

修订后重新运行六面探针与六原型各2秒静置，支撑95%–105%、裸核心—桌面接触0、越过1mm皮层的内容物角点0、数值有限且overflow=0。GPU两拓扑各64个异构环境2秒，检查有限状态与容量。重新测N=1/64/512/2048/4096，dt=62.5μs、warmup400步、计时200步，注明该计时窗口覆盖初始接触过渡态。正式运行均在ubun持flock。若局部细化导致包覆失败，修正后重跑相同标准。YAM同原型同seed、顶面、dt125μs、1ms接触配置仅运行一次完整动作，保留失败结果，沿用10N闭合目标与原成功判据。

补充入口检查各一次：历史envelope=False行为测试；新版YAM 0.03秒smoke检查配置、实际膜参数和MJB导出，smoke仅检查入口。六面隔离夹膜夹具以新参数、dt62.5μs复测各面两种外载0.02/1N各0.1秒，要求数值有限且初始记录的face_id正确。夹具预先把膜放在两个夹头之间，载荷不足以检验最大摩擦容量，结果仅用于接触接口检查。

4096三段测速r1失败，overflow=512，对应原生Newton求解器100次迭代上限。其余规模/拓扑通过，失败项不计入通过性能。该批次出现3条损伤边，需区别实际有限强度失效与数值发散。对相同4096环境、相同600步工况检查更高的有限200次迭代上限，记录各异常环境、最大速度/边长比与损伤。收敛/有限性/overflow标准保持不变。

200次诊断消除了迭代溢出，但环境3224出现边长比54.56、12条损伤边，属于不可信的动态爆发，不能按“有限即稳定”认定通过。先保持材料参数，采用半步长31.25μs对相同4096环境运行相同物理时长0.0375秒，检查该环境的边长比、膜节点速度、膜损伤和求解器标志。必要时继续分析显式弯曲阻尼的刚性，禁止用提高破坏阈值隐藏爆发。

半步长诊断避免了3224的伸长爆发，但另一个环境3574仍触及200次迭代上限。进一步修正弯曲阻尼等效惯量，原先只用一条边两端质量和边长估计，未反映局部细化后相邻三角形的高度。现在使用四节点的二面角梯度q，I_eff=1/Σ(|q_i|²/m_i)，c_b=2ζ_b√(k_b I_eff)。角速度Σ(q_i·v_i)已与原atan2法向导数独立对照通过，耗散与刚体运动客观性测试通过。

为识别已观测到的数值爆发，静置测试与测速补充检查损伤边为0、最大边长比<2。此标准针对本轮无破坏加载的静置工况，不用于受拉破坏试验。先以当前默认100次迭代、62.5μs对同样4096环境/两拓扑各0.0375秒检查，再重跑64环境2秒、六类支撑与回弹对照。该修正只改变阻尼模态惯量，材料刚度、强度、动作、接触阈值与随机种子保持一致。

四节点惯量修正后，同一4096批次、默认100次迭代、62.5μs、0.0375秒的两拓扑检查通过，无损伤且overflow=0。最终自由回弹对照1秒归一化机械能为旧参数11.348%、新参数1.512%。之前0.0416%的数字对应惯量近似版，该版本在4096环境出现动态爆发，作为失败/修正记录保留。完成当前64环境/六类支撑复验后，以修正后的膜参数补跑同一YAM原型3/seed7完整顶抓1次并保存实际过程，判据保持原值。
