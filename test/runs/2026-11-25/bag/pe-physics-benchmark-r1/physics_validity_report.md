# PE 袋基准物理有效性

Flex 复用仓库确认的 `physical_parcel.Parcel`，保留原生二维膜面弹性与仓库的二面角弯曲。VBD 复用 `newton_bag.NewtonBag`，使用同一封边参考膜、初始化、面积分配质量和刚体尺寸。整袋为 142 节点、280 三角面、0.175 m²，膜总重 9.66 g，参考最长边 50.005 mm。袋子初始化和材料边界之外不定位膜点或内芯。工具对内芯的刚体碰撞被明确屏蔽。标准台面允许刚体触地，触地单独计数。[配置](flex_config.json) · [VBD 配置](vbd_config.json) · [输入一致性](manifest.json)

Flex 工程材料为 60 μm 厚、55.2 g/m²、面内刚度 1200 N/m、弯曲刚度约 3.96×10⁻⁷ N·m。数值碰撞半径 0.25 mm。VBD 以对应 SI 材料量作为初值，使用自身 Neo-Hookean、二面角和 penalty 接触，不共享摩擦/阻尼的底层实现。Flex 25 μs，VBD 50 μs。1,010 节点、14.142 mm 最长边的 Newton Yam_B 试验采用另一种 220×160×36 mm 封闭盒形袋，0.5 ms 和独立耦合模型。该历史结果未混入这次同拓扑对照。[历史试验](../../isaaclab/newton-yam-medium-bag-r1/)

## 生效门槛

有限状态和接触反力、无求解器告警或容量溢出、最大边长比 ≤1.05、接触深度和台面几何侵入 ≤1 mm。包覆另检查膜三角形对内缩 1 μm 名义盒体的 SAT 交叉及八个原角点的 winding number。膜自交叉独立用非邻接三角形边对面相交，配合对应膜节点高度差、有效自接触力及接触深度。原回合采样间隔 2 ms，复放为 1 ms，瞬时样本不能排除采样之间的短暂穿越。配对高度差只用于解释对应层，折叠下不能当作全局最短距离。接触候选与有效反力分开。

静止的门槛是末 0.10 s 节点质量加权 RMS 速度 ≤5 mm/s。B05-A 的支撑误差限为 5%。B06 诊断检查 5 N 实际反力上限，无穿越和刚体旁路。载荷试验的能量升高包含外功，不能用无载能量门槛判为发散。两种接触模型的自接触法向和具有各自的离散化定义，外部夹具合力才是载荷直接对照。

## 定位及复核

- **Flex B01** 测得末段峰值 50.93 mm/s、几何台面侵入 0.089 mm、零采样膜穿越。1.08 s 同态复放中，原设置末段运动几乎全是竖直速度。单独关闭自接触使残余振荡消失，同时出现 124 对穿越。半步长降低振荡。2、3、4 ms 自接触时间常数继续降低末段波动，按相同 0.10 s 窗口，3 ms 为 7.09 mm/s，4 ms 为 5.84 mm/s。继续保留原静止门槛。
- **Flex B04-U** 有限盒台面原条件在 0.218 s 开始出现膜交叉，最多 5 对，法向求解深度峰值 1.421 mm。半步长和放软自接触均未消除穿越。1.8 倍轨迹时间消除已采样穿越，但最大深度仍 1.560 mm。仅恢复现有模型常用的平面台面，保留原压板运动，结果为零穿越，最大深度 0.436 mm，几何台面侵入 0.180 mm。平面台面复测通过。
- **Flex B05-D** 350 g 内芯由定位封边的材料边界提起 52.2 mm，边长比 1.0537。改为 1.8 倍轨迹时间后，同位移动作提起 40.7 mm，最大边长比 1.0377，零采样膜和内芯穿越，原门槛通过。边界驱动属于承载材料试验。
- **VBD 反力修复** Newton 1.6.1 刚体侧邻接表只包含有正有效逆质量的动态刚体。早一版读取遗漏了台面和运动学压头。修正后以参与粒子求解的 barycentric 记录及同一 VBD 力函数重建反作用，容量越界单列。旧回合的几何 SAT 与 winding 检测仍有效，旧的运动学夹具零值留作读回故障证据。
- **B06 限幅** 首轮 2 ms 读回触发点出现 Flex 43.43 N。初态夹具显示高度也在首轮报告读成停放高度。汇总由规定的起始目标重算位移，显式将超 5 N 回合归为失效。原始回合及两种坐标均保留。慢程独立复测在 4 N 触发，逐子步峰值 4.0048 N。该时刻有 2 条膜—探针、38 条膜—内芯正法向力接触，没有刚体旁路。0.05 N 以上只出现一个 25 μs 采样，现有波形无法估计稳态接触刚度。VBD 修正读取后的快程记录到 59.58 N，同时 2 个内芯角点露出。
