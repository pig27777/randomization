## 选择

1. 现有 Flex 达到首轮静态包覆和低应变拉伸目标，可留作参考。空袋静止、压缩顺应性及快程探测仍限制项目验收。
2. VBD 在同一台机器和参考几何下显著降低末端节点速度，U 折也减少可采到的几何交叉。局部卸载拉伸、U 折伸长和带载露角是仍需解决的证据。
3. 主动 Try 可从 Flex 的慢程单点传力继续做验证。当前没有可靠的多位置可辨识证据能给出后端排名。首轮 Flex 同位轨迹下空袋峰值 14.70 N，偏置探点 5.53 N，正对内芯 43.43 N。三者均越限，偏置点还出现穿越。慢程只有正对内芯的诊断，幅值不与那三条曲线混合。
4. 局部薄膜夹持、隔袋夹持、滑移与释放尚无本轮合格样本，三者的后端选择仍待测。
5. GPU 方面只验证了运行能力。现有结果无法排序有效吞吐或显存，也无法支持整体迁移。
6. 保留 Flex 参考通道与 VBD 候选通道，待同负载的接触、膜面和力平衡均通过后，再判断是否采用参考后端加训练后端的组合。高保真参考资格还需要真材和真机力学数据。
