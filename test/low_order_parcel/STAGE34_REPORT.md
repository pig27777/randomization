# Stage 3–4 域随机化与双探针策略

## 本轮计划（2026-11-21，ubun）

使用 369ce7bd 的 Stage 2.5 台架，每步 2 ms、float32。使用项目解释器及独立的 PyTorch 2.7.1+cu128 依赖目录，RTX 5090 的正式运行共用 GPU 锁。本轮动作作用于四块模板的指垫接口。机械臂级迁移另需在 YAM 平台验证。

1. Stage 3 检查材料相关性、质量与填充范围、局部重置隔离、独立指摩擦和硬件队列延迟。C1 另测 5 N/s 的切向脱手载荷。C1–C8 每角以固定物理参数并行搜索连续动作。保留所有失败。通过条件为每角至少一组双指捕获、桌面净空 >1 mm、支撑为零且质心速率 <20 mm/s 连续 1500 步。固定角点的物理参数不随搜索优化。
2. Stage 4 以三种子 17、31、53 做独立训练和留出评估。八种方法使用同一真实代理和留出域。前 20% 强制均衡模式，窄域达到 85% 才释放宽域。按更新记录包含重置、传感、物理步进及 PPO 的墙钟、训练环境步和 GPU 小时。以连续三个留出评估达到 85% 且每角均出现成功作为本轮“稳定”的操作定义。报告书/衣模式、补抓、成功率和角点逐项结果。失败时保存首次失效与预算内最好的记录，不放宽阈值。
3. 冻结门禁 A（两档各六工况）、B（含两档各百万步）、C（20 原测试）各复跑一次。Stage 3 的物理门禁失败时，继续检查 Stage 4 实现和对照入口，按实际评估结果标记正式收敛状态。

## Stage 3A 双臂 Step 1（2026-11-21，ubun）

本轮计划。用 2 ms、float32、固定种子的批量台架各验证一次零半饱和力的代理等价、0.3 N 与 3.0 N 的同袋衣物抓取分岔、20–60 N 逐指撕裂、同时聚拢的共享余料、空中侧壁净进给和 65 g 拉拔。重压须双指捕获并离台，轻压须抓取失败。撕裂指须在当步停止传力。拉拔须由双臂实际反力经最坏库仑项与延迟滤出双侧大于 3.5 N 的对拉脉冲。感知单测覆盖 YAM 和 RGB 的独立延迟、复位及观测退化。复跑 Stage 2 七项、Stage 2.5 P1–P4 和整包二十项。CUDA 单测持 GPU 锁。

Step 1 通过后交付本轮代码与结果。若有失败，保留原因、复测记录和已知边界，修复后再判定。

`MacroParcelSim.step(state, action)` 已提供双指 `ParcelAction` 和侧壁接触台架。`LumpedContactProxy.step(state, inputs)` 接收每臂 `[B,2,6]` 状态和 `ContactInputs.S_bag_eff[B,1]`。`UnifiedPayloadTemplate.step(state, force, depth)` 接收四块外力 `[B,4,3]`，同时提供双线性挂点、压陷几何和 54 维特权状态。

`DualArmParcelSim.step` 接收两份 `ParcelAction` 和活动臂掩码，保持两臂接触状态独立。当前压陷的余料增量取两组挂点估算的较大值，避免同一凹陷重复计账。当两臂同时争用余料时，先保留两臂已有余额，再按需求比例限额，并用冻结代理重算当步滑移、捕获和张力。载荷按四个挂点权重叠加，越限指在向模板传力前断载。侧壁的接触弹性与台架一致，作用范围延伸至空中。

`YAMCurrentEstimatorFilter` 独立返回两臂估力、夹爪通道与编码器误差。`VirtualRGBProjector` 标定顶相机工作平面与腕相机 FK 深度，用 32 个包络角点近似两路掩码。两类观测器维护独立的历史环形队列，并接受局部复位和回合级参数更新。

CPU 与 RTX 5090 各 11 项通过。0.291 N 轻压零捕获，2.897 N 重压双指捕获、离台 37.279 mm。共享预算 0.150 mm，含同时聚拢及当步抽离。343.97 N 试算张力在 60 N 门限下当步归零。65 g 拉拔真值峰值 5.126 N，CUDA 退化估力双侧同时超过 3.5 N 达 76 ms。侧壁接触和横向夹压互斥后，两个运行环境的空中侧推峰值均为 3.011 N。原代理 7 项、两档对齐各 6 工况、P1–P6 与挂点虚功共 9 项、旧代理 CUDA 8,192 路及整包 20 项通过。[任务检查](../../reports/stage3a-dual-arm-test.md)

## Stage 3B Step 2（2026-11-21，ubun）

本轮计划。使用 85cb6f0e 双臂台架，float32、2 ms。检查全宽分布、35% 硬包、30% 侧向遮挡、课程缩放、两臂硬件独立性、局部复位和固定角点参数。C1 用 5 N/s 切向增载检查 0.45–0.65 N 脱手。C1–C8 每角用 128 个固定种子 Sobol 动作起跑，至少一个动作须双指捕获、离台 >1 mm、零支撑、质心速度 <20 mm/s 连续 1,500 步且全程无撕裂。C9–C10 从规定的 A 臂持有初态出发，B 臂须闭合并捕获，A 松手后 B 独立悬空稳持 250 步，且包裹始终未离手或撕裂。C10 另需双臂退化读数同时呈现 >3.5 N 拉拔脉冲。出现未通过角点时保留失败轨迹和参数，按实际首个失效调整动作搜索，固定角点物理与判据。Step 2 证据来自指垫仿真，训练门禁沿用独立的物理审计。正式 CUDA 运行持共享锁。

全宽 Tier 1 先按整袋等效 [4, 5000] N/m 对数均匀采样，再选覆盖该刚度的材料并按原材料相关性采样其他参数。左右指摩擦不对称与压陷半饱和力独立配置。Tier 2 用填充联锁余料和内部滑移，采样硬物比例 34.6%、有侧向遮挡 30.1%（CUDA 16,384 路）。Tier 3 支持双臂独立退化、课程渐增和批内局部复位。高位侧抓由动作明确指定进给方向，使袋膜聚拢可以使用夹爪局部法向力。

RTX 5090 单入口每角并行 1,024 个动作，C1–C10 均找到零捕获预载、无掉落及撕裂的轨迹。C1 在 0.560 N 脱手。C3 仅 3/1,024，C7 仅 1/1,024；C7 在 16.5 s 回放稳持 8.156 s，延长压力跑在稳持 9.636 s 后撕裂。C9 和 C10 分别稳持 6.848 s 和 3.394 s，C10 双臂退化读数同时超过 3.5 N 达 40 ms。验证只覆盖冻结低阶仿真中的可行性，训练准入仍以独立物理审计为准。[测试报告和逐角数据](../../reports/stage3b-corners-test.md)

## Stage 4 Step 2（2026-11-22，ubun）
