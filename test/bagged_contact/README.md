# 隔膜传力基准：刚体 → 膜 → 四面体

物流场景里夹爪接触的是袋子，袋子再压内容物。本基准检验这条真实链路，作为“内容物和袋子是否统一用 Newton VBD”的判别实验。它沿用 `../contact_transfer/` 的软块、测量工具和验收阈值，以及 `../gripper_grasp/` 的夹取流程，只把刚体直接接触四面体换成隔着一层膜。

状态：2026-11-03 定义并实现（A：`../contact_transfer/benchmark.py` 的 `membrane_*` 工况；B：本目录 `bagged_grasp.py`），第 1 轮运行中。每轮计划和结果写在 [REPORT.md](REPORT.md)。

## 为什么需要它

- 刚体 → 膜：袋子线已能运行，但没有在膜下面放软体时检查过。
- 膜 → 四面体：加摩擦后，ke 30/300 随步长和迭代收敛（`../contact_transfer/REPORT_newton170.md`），但只测过均布加载。小工具隔膜局部压下时，膜会不会穿入软块没有测过。
- 膜–四面体接触刚度是 `model.soft_contact_ke`（粒子间接触）；刚体–粒子接触刚度是形状 `ke` 与 `model.soft_contact_ke` 的算术平均（Newton 1.7 `init_body_particle_contacts`；kd 同样平均，μ 取几何平均）。两者可以分开设定，但要把形状 `ke` 设为 `2 × 目标值 − soft_contact_ke`（与 `bag_sim/newton_bag.py` 的做法相同）。所以“ke 30 软到小手指会穿过”只针对刚体直接压四面体，不能直接套到隔膜场景。
- 刚体直接压四面体的平面积分修法（`../contact_transfer/planar_contact.py`）只作用于软块顶面三角形，不覆盖刚体 → 膜。刚体压在膜节点之间时，是否会出现同样的边/面取点跳动，需要本基准回答。

## A. 隔膜平压

| 项目 | 设置 |
|---|---|
| 软块 | 同 `contact_transfer`：300 × 250 × 50 mm，0.3 kg，μ = 1500 Pa、λ = 1000 Pa，阻尼 1 Pa·s，12 × 10 × 4 格；底层固定，无重力 |
| 膜（`bench`） | 同 `contact_transfer` 的 `membrane`：240 × 200 mm，20 mm 网格，12 g，tri_ke 5000、tri_ka 2000 N/m，粒子半径 4 mm，初始高度 59 mm |
| 膜（`bubble`） | 按 `../../bag_sim/profiles/bubble.json`：E·t = 2e7 Pa × 2 mm，ν = 0.3，面密度同气泡袋（12 g / 0.0864 m²），碰撞半径 1.75 mm，网格约 10 mm；软化规则与 `newton_bag.py` 相同。膜和软块的初始间距 ≥ 两者接触距离之和 + 0.2 mm，避免自接触势垒一开始就把膜弹开 |
| 工具 | 压板 240 × 200 mm、19.62 N；手指 20 × 20 mm、2 N，位置取 (0, 0)（软块节点和膜节点正上方）和 (12.5, 12.5) mm（两者的节点之间） |
| 驱动 | 正式：力驱动 + 竖直滑轨（同 `contact_transfer`），0.2 s 平滑加载。诊断：位移控制，用于区分耦合振动和接触本身 |
| 接触 | 刚体 → 膜：原生全表面接触，ke 3000、kd 3，μ 0.5。膜 → 软块：粒子接触，ke 300、kd 0.3，μ 0.5，ε 0.01 m/s |
| 步长 | 0.1 ms、10 次迭代为基准；收敛对照 0.05 ms、10 次迭代 |
| 时长 | 记录 2 s 和 8 s 两个时刻的末段指标，分别报告，不合并 |

**验收**（末段 0.5 s 平均，阈值与 `contact_transfer` 相同）：

1. 底部支撑反力与载荷误差 ≤ 5%；工具反力误差 ≤ 5%；四面体活动节点残差 ≤ 载荷的 5%。
2. 膜 → 软块的接触合力与载荷误差 ≤ 5%。这是本基准新增的一项，用来确认力确实经过膜传下去，而不是绕过去。
3. 几何穿透：膜节点低于软块变形表面 ≤ 0.05 mm；工具底面低于膜表面 ≤ 0.05 mm。
4. 无四面体翻转；下陷漂移 ≤ 0.05 mm；最大速度 ≤ 1 mm/s。
5. 另记中位速度、50 ms 平均速度、超过 1 mm/s 的节点数和膜的最大面积拉伸，作为辅助判断。

步长从 0.1 ms 减半到 0.05 ms 时，下陷变化 ≤ 2%、支撑力变化 ≤ 1%，才算数值收敛。

## B. 隔膜夹起

| 项目 | 设置 |
|---|---|
| 内容物 | 同 `gripper_grasp` 的硬海绵：120 × 80 × 50 mm，0.3 kg，μ = 6000 Pa、λ = 2000 Pa，12 × 8 × 5 格；有重力，放在地面上 |
| 袋子 | 封闭长方体膜，包住海绵，每边留出 ≥ 接触距离之和 + 0.2 mm 的间隙；参数用 A 中的 `bubble`，网格约 10 mm，质量按面积计（约 5 g） |
| 指垫 | 40 × 10 × 40 mm，4 mm 圆角，运动学驱动；中心偏移 0 和 5 mm；夹紧量 30%；流程和时长同 `gripper_grasp`（静置 0.3 s、合拢 0.5 s、夹住 0.3 s、提起 50 mm 用 1 s、保持 1 s） |
| 摩擦 | 指垫–袋 0.8，袋–海绵 0.5，袋–地面 0.5；ε 0.01 m/s |
| 接触 | 指垫 → 袋：ke 3000、kd 3；袋 → 海绵：ke 300、kd 0.3 |
| 步长 | 0.25 ms、10 次迭代 |
| 对照 | 同一设置去掉袋子，即直接夹海绵（用现有 `grasp.py`），用于区分哪些变化是袋子带来的 |

**验收**（保持阶段末 0.5 s）：

1. 海绵质心升高 ≥ 提升量的 90%。
2. 承重链路，两段都用逐子步冲量积分，并做动量核对：
   - 指垫 → 袋的竖直合力等于（海绵 + 袋）的重量，误差 ±5%；
   - 袋 → 海绵的竖直合力等于海绵重量，误差 ±5%；
   - 两段的动量残差都 ≤ 5%。
3. 两侧夹持力相差 ≤ 5%。
4. 下滑 ≤ 0.1 mm/s。已知 ε = 0.01 时，不隔膜也会以约 0.7 mm/s 下滑；如果只差这一项，记为摩擦正则化问题，不判为隔膜传力失败。
5. 无四面体翻转；膜节点穿入海绵 ≤ 0.05 mm；袋子没有被指垫穿透。
6. 速度：同 A 的第 4、5 条。

## 实现约定

- A 优先在 `../contact_transfer/benchmark.py` 上加选项（例如 `--case membrane_plate`、`--membrane bench|bubble`），复用现有测量。B 优先在 `../gripper_grasp/grasp.py` 上加 `--bag`。如果改动会影响原有场景，就在本目录新建脚本，并导入原有的测量函数。
- 原有场景必须先回归：`guided_base_finger` 和 `grip_dt0p25_firm_off5` 的关键数值不变，才能开始本基准。
- 正式运行用 `flock /tmp/claude-gpu.lock <命令>` 串行执行。结果分别写在 `../contact_transfer/results/` 和 `../gripper_grasp/results/`，tag 以 `bag_` 开头。
- 实际实现（2026-11-03）：
  - A：`benchmark.py --cases membrane_plate|membrane_finger|membrane_finger_off --membrane bench|bubble`。`--ke/--kd` 是工具 → 膜，`--membrane-ke/--membrane-kd` 是膜 → 软块；`--checkpoints 2` 在 8 s 运行里另算 2 s 时刻的末段指标。膜 → 软块合力取软块节点上的粒子接触力；另记刚体直接作用在软块上的力（应为 0）以及软块、膜各自的最大速度。工具初始底面在膜接触面上方 0.2 mm。
  - `bubble` 膜：E·t、ν、面密度、半径按 `bubble.json`；按 `newton_bag.py` 的规则（courant 0.7、最小子步 0.05 ms）软化到 17.7%；膜–软块接触距离取 2 × 半径 = 3.5 mm。弯曲取 K/格距，没有复用袋子线的逐铰链刚度和折痕软化。
  - B 改动会进入 `grasp.py` 的建模流程，因此按上条新建 `bagged_grasp.py`，导入 `grasp.py` 的常量、指垫轨迹和测力核，原脚本不变；对照组 B2 直接用 `grasp.py`。指垫闭合位置使海绵的名义夹紧量与对照组相同（30%），即在对照组闭合位置上加膜的叠层厚度（膜半径 + 膜–海绵接触距离 = 5.25 mm/侧）。海绵粒子半径取膜半径 1.75 mm，这样任何指垫或地面直接作用在海绵上的力都表示穿透，单独记录。
  - B 的速度判据按 A 第 4 条取海绵和袋子节点最大速度 ≤ 1 mm/s；对照组 `grasp.py` 自带的 `quiet` 判据是中位 ≤ 1、最大 ≤ 10 mm/s，两者在报告中分开列。
  - 运行脚本：`run_round1.sh`。
